# Контекст проекта CRM

## Проект

CRM на Node.js/Express/PostgreSQL с клиентом React/Vite. Основная текущая задача — рассылки и привязка получателей к виду рассылки (сохранённому шаблону письма).

## Текущая реализация рассылок

- У получателя есть `recipients.mailing_template_id`.
  - `NULL` = «Ручной ввод».
  - ID шаблона = назначенный шаблон, например «Приветствие».
- Список получателей возвращает и показывает название вида рассылки.
- В ручном добавлении получателя есть выбор вида рассылки.
- Импорт Excel двухэтапный: preview → решения по конфликтам → confirm.
  - Шаблон предлагается по имени файла, например `Рассылка Приветствие.xlsx`.
  - Выбор можно изменить до preview.
  - При совпадении email с другим видом рассылки доступны действия: пропустить или заменить шаблон, включая массовые действия.
  - Внутри Excel дубликаты email: остаётся последняя строка.
- Фильтр по виду рассылки есть в таблице получателей.
- При выборе фильтра сохранённого шаблона его тема и тело подставляются в форму письма.
- При выборе получателей с одним общим сохранённым шаблоном он также автоматически подставляется в форму.
  - При «Ручном вводе» или смешанных видах шаблон не подставляется.
  - После автоподстановки оператор может вручную сменить шаблон, тему и тело: выбор не должен повторно перезаписываться без смены выбранных получателей.

## Основные файлы

- `db/migrations.js` — миграции, включая `mailing_template_id` и `recipient_import_drafts`.
- `db/index.js` — логика получателей, импорта, конфликтов и истории изменений.
- `controllers/recipientController.js` — HTTP endpoints preview/confirm импорта.
- `routes/api.js` — маршруты импорта.
- `client/src/api/index.js` — API-клиент.
- `client/src/context/AppContext.jsx` — состояние рассылки и автоподстановка шаблонов.
- `client/src/pages/MailingPage/components/ImportArea.jsx` — импорт Excel.
- `client/src/pages/MailingPage/components/Filters.jsx` — фильтр вида рассылки.
- `client/src/pages/MailingPage/components/RecipientsTable.jsx` — отображение вида рассылки.
- `client/src/pages/MailingPage/components/AddRecipientModal.jsx` — ручное создание получателя.
- `client/src/pages/MailingPage/components/EmailForm.jsx` — форма письма и подсказки о выбранном шаблоне.

## Проверки

Последняя клиентская сборка прошла:

```bash
npm --prefix client run build
node --check controllers/recipientController.js
node --check db/index.js
node --check db/migrations.js
node --check services/excelService.js
git diff --check
```

Реальная отправка, импорт и миграции на рабочей БД не запускались в рамках последних изменений — их проверяет пользователь.

## Важные ограничения

- В рабочем дереве есть незакоммиченные изменения: не откатывать и не перезаписывать их без явного запроса.
- Не выполнять реальные операции с БД без явного запроса.
- Не создавать/редактировать DOCX и не загружать DOCX-шаблоны в БД без отдельного запроса.
- Не коммитить и не отправлять изменения без явного запроса.
