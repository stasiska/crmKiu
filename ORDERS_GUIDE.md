## 📋 Инструкция по использованию

### Для пользователей

#### 1. Создание приказа о зачислении

1. Откройте карточку группы (кликните на группу в списке)
2. Перейдите на вкладку **"Документы"**
3. Нажмите кнопку **"+ Сформировать приказ"**
4. В открывшемся окне:
   - Выберите тип приказа: **"О зачислении"**
   - Введите номер приказа (например: `ПП 11/11/2026`)
5. Выберите действие:
   - **"Сгенерировать и посмотреть"** - скачает документ для предпросмотра (не сохраняется в базе)
   - **"Прикрепить к группе"** - сгенерирует и сохранит документ в базе данных
   - **"Загрузить свой вариант"** - позволит загрузить отредактированный .docx файл

#### 2. Работа с документами группы

На вкладке **"Документы"** в карточке группы вы увидите:
- Список всех документов группы
- Тип приказа (О зачислении, О выдаче документов и т.д.)
- Номер приказа
- Имя файла
- Дату создания
- Автора документа
- Способ создания (сгенерирован автоматически или загружен вручную)

Действия с документами:
- **Скачать** - загрузить документ на компьютер
- **Удалить** - удалить документ из базы данных

#### 3. Требования к данным группы

Для корректной генерации приказа о зачислении необходимо заполнить в группе:
- ✅ **Наименование курса** (course_name) - обязательно
- ✅ **Подразделение** (branch) - должно совпадать с названием филиала из справочника
- ✅ **Часы** (hours) - количество часов курса
- ✅ **Дата начала** (start_date) - используется как дата приказа
- ✅ **Дата окончания** (end_date)
- ✅ **Менеджер** (manager_id) - ответственный за направление
- ✅ **Слушатели** - должны быть добавлены в группу

#### 4. Склонение ФИО слушателей

Система автоматически склоняет ФИО в винительный падеж с помощью библиотеки Petrovich.

**Если автоматическое склонение работает неправильно:**
1. Перейдите в карточку слушателя
2. Заполните поле **"ФИО в винительном падеже"** (name_accusative)
3. Введите вручную: например, `Иванова Ивана Ивановича`
4. При генерации приказа будет использоваться это значение

### Для администраторов

#### 1. Управление филиалами

**Просмотр филиалов:** `GET /api/branches`

**Добавление филиала:**
```bash
POST /api/branches
{
  "code": "spb",
  "name": "СПб филиал КИУ (ИЭУП)",
  "director_name": "А.А. Александров",
  "city": "Санкт-Петербург"
}
```

**Обновление филиала:**
```bash
PUT /api/branches/:id
{
  "director_name": "Новое ФИО директора"
}
```

#### 2. Управление шаблонами документов

**Список шаблонов:** `GET /api/document-templates`

**Загрузка нового шаблона:**
```bash
POST /api/document-templates
Content-Type: multipart/form-data

file: [выбрать .docx файл]
code: "issuance_order"
name: "Приказ о выдаче документов"
description: "Шаблон приказа о выдаче документов об образовании"
```

**Обновление шаблона:**
```bash
PUT /api/document-templates/:id
Content-Type: multipart/form-data

file: [новый .docx файл] (опционально)
name: "Новое название"
is_active: true
```

## 🔧 Техническая информация

### Плейсхолдеры в шаблоне

При создании нового шаблона используйте следующие плейсхолдеры:

| Плейсхолдер | Описание | Пример |
|-------------|----------|--------|
| `{order_date_formatted}` | Дата приказа (DD.MM.YYYY) | 15.01.2026 |
| `{city}` | Город филиала | Казань |
| `{order_number}` | Номер приказа | ПП 11/11/2026 |
| `{branch}` | Название филиала | ЧФ КИУ (ИЭУП) |
| `{course_name}` | Наименование курса | Бухгалтерский учет |
| `{hours}` | Количество часов | 504 |
| `{start_date_ru}` | Дата начала (русский формат) | 15 января 2026 года |
| `{end_date_ru}` | Дата окончания (русский формат) | 05 июня 2026 года |
| `{listeners_numbered_list}` | Нумерованный список слушателей | 1. Иванова Ивана Ивановича<br>2. Петрову Петру Петровичу |
| `{director_name}` | ФИО директора филиала | Н.И. Мухаметханова |
| `{manager_name}` | ФИО менеджера группы | И.И. Иванов |

### Зависимости

Установлены следующие npm-пакеты:
- `docxtemplater` - рендеринг Word-документов
- `pizzip` - работа с ZIP (docx - это ZIP архив)
- `petrovich` - склонение русских ФИО по падежам

### Структура базы данных

**Таблица `branches`:**
```sql
CREATE TABLE branches (
  id SERIAL PRIMARY KEY,
  code VARCHAR(50) NOT NULL UNIQUE,
  name VARCHAR(255) NOT NULL,
  director_name VARCHAR(255),
  city VARCHAR(100),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Таблица `document_templates`:**
```sql
CREATE TABLE document_templates (
  id SERIAL PRIMARY KEY,
  code VARCHAR(50) NOT NULL UNIQUE,
  name VARCHAR(255) NOT NULL,
  description TEXT,
  file_data BYTEA NOT NULL,
  file_name VARCHAR(255),
  is_active BOOLEAN DEFAULT TRUE,
  created_by INTEGER REFERENCES users(id),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Таблица `group_documents`:**
```sql
CREATE TABLE group_documents (
  id SERIAL PRIMARY KEY,
  group_id INTEGER NOT NULL REFERENCES groups(id) ON DELETE CASCADE,
  template_code VARCHAR(50) NOT NULL,
  order_number VARCHAR(50),
  file_data BYTEA NOT NULL,
  file_name VARCHAR(255),
  is_uploaded BOOLEAN DEFAULT FALSE,
  created_by INTEGER REFERENCES users(id),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## ❓ Часто задаваемые вопросы

**Q: Как изменить шаблон приказа?**  
A: Только администратор может обновить шаблон через API `PUT /api/document-templates/:id`

**Q: Можно ли использовать свои шаблоны?**  
A: Да, администратор может загрузить новый шаблон через API `POST /api/document-templates`

**Q: Что делать, если ФИО склоняется неправильно?**  
A: Заполните поле "ФИО в винительном падеже" в карточке слушателя вручную

**Q: Как добавить новый филиал?**  
A: Администратор может добавить через API `POST /api/branches`

**Q: Где хранятся документы?**  
A: Все документы хранятся в базе данных PostgreSQL в бинарном формате (BYTEA)
